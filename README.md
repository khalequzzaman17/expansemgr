# Expense Tracker

An Android personal-finance application for recording transactions, managing accounts, setting budgets, tracking savings goals and debts, and reviewing financial reports.

## Features

- Income, expense, and account-transfer records
- Account and wallet balance tracking
- Categories, search, sorting, and filters
- Monthly and category budgets
- Recurring transactions and reminders
- Savings goals and debt or lending records
- Financial reports and spending trends
- CSV/PDF export and local backup/restore
- PIN lock and biometric unlock
- English and Bangla language support

## Technology

- Kotlin and Android SDK
- Room Database
- Android Jetpack ViewModel and Lifecycle
- Kotlin Coroutines and Flow
- WorkManager
- DataStore Preferences
- Android Biometric and Security Crypto

## Requirements

- Android Studio
- JDK 21
- Android SDK 36

## Build

Open the project in Android Studio and run the `app` configuration, or use:

```bash
./gradlew assembleDebug
```

On Windows:

```bat
gradlew.bat assembleDebug
```
